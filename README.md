# ling-coordinate-pointer
添加了一个可输入坐标的指针和指南针类似，可以手动输入坐标然后会指向该坐标方位只需要手持蹲下就可以打开界面，做这个mod的初衷是为了联动机械动力：航空学的导航台，让他导航到自己手动输入的坐标

I've added a coordinate-input pointer similar to a compass. You can manually enter coordinates, and it will point toward that location. Hold the item and crouch to open the UI. This mod was originally made to work with the Navigation Table from Create: Aeronautics, allowing it to navigate to coordinates you manually input.
